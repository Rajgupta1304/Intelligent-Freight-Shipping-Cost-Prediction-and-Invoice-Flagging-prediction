# Shipping Cost Prediction

A machine learning project that predicts shipping costs using customer/order-related data.

## 🚀 Project Overview

This project uses **Python, Pandas, NumPy, and Scikit-learn** to build a machine learning model for predicting shipping costs. The trained model is deployed using **Streamlit**, providing an easy-to-use web interface for making predictions.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Streamlit
* Machine Learning

## 📌 Features

* Data preprocessing and analysis
* Feature selection and preparation
* Machine learning model training
* Shipping cost prediction
* Interactive Streamlit web application

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

Start the Streamlit application with:

```bash
streamlit run app.py
```

The application will open in your browser, where you can enter the required details and get the predicted shipping cost.

## 🤖 Machine Learning

The project uses **Scikit-learn** for preprocessing, training, and prediction. The model learns patterns from historical shipping/order data and uses those patterns to estimate shipping costs for new inputs.
